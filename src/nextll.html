NextLL

One attraction, one goal. Pick a ride, tap Find it, and it takes the first Lightning Lane it can get and then keeps trying to move it earlier.

Install

Copy this, then save it as a bookmark whose address is the copied text:

The rest is identical to installing AutoLL, so follow its instructions for your browser — just paste this code instead of that one. Give the bookmark a name you will recognise, like NextLL.

Use

  1. Open disneyworld.disney.go.com/vas/ and sign in.
  2. Run the NextLL bookmark.
  3. Choose the attraction, optionally a “return by” time.
  4. Tap Find it and leave the screen in front of you.

It shares its login, action budget and attraction data with AutoLL, but keeps its own watch list, so starting it will not disturb whatever AutoLL is watching.
